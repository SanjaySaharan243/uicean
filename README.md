# UICEAN

An independent creative library for expressive interface components, website blocks, templates, and visual experiments.

## Local development

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run typecheck
npm run build
```

The current experience is frontend-only and uses local TypeScript catalog data. Favorites and theme selection are stored in the browser. Authentication, purchasing, and package distribution need service configuration before launch.
